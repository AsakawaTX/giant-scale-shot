# giant-scale-shot 巨物感镜头

一个通用的 Agent skill：把任何角色巨大化，写出写实、震撼、有巨物感的视频提示词。

包含四部分：
- 风格：环境超写实，主角可以保持二次元风格。
- 镜头：镜头站在人的位置，去看一个画面装不下的东西，附一份可挑选的镜头菜单。
- 动作：巨物服从地球引力，慢、有重量、有惯性。
- 声音：低沉、有回响、比画面晚到。

## 使用

把 `SKILL.md` 放进你的 Agent 的 skills 目录，或者直接把内容发给 Agent，然后告诉它：

> 用巨物感镜头 skill，把参考图里的角色巨大化，写一个 10 秒的视频提示词。
