# giant-scale-shot 巨物感镜头

一个给 AI 用的 skill：把任何角色（怪兽、机甲、二次元角色……）巨大化，写出**写实、震撼、有巨物感**的 AI 视频提示词。

## 它解决什么问题

很多 AI 生成的巨物镜头看起来像手办在打架：镜头飞在天上，巨物动作轻快，画面干净明亮。这个 skill 把真正有巨物感的电影手法整理成 AI 能直接用的逻辑：

- **风格**：环境超写实电影实拍质感；主角可以保持二次元风格，和写实世界形成反差。
- **镜头**：镜头永远站在"人"能站的位置，去看一个画面装不下的东西。内置一份可挑选的镜头菜单：用影响暗示、隔着玻璃看、只拍局部、拿参照物比、冲击与余波等。
- **动作**：巨物服从地球引力，慢、有重量、有惯性，不做灵巧动作。
- **声音**：低沉、有回响、声音比画面晚到。

主要参考《环太平洋》第一部，以及《哥斯拉》2014、《哥斯拉-1.0》、《进击的巨人》、《沙丘》2021、《科洛弗档案》。

## 使用

把 `SKILL.md` 放进你的 AI 工具的 skills 目录，或者直接把内容贴给 AI，然后告诉它：

> 用巨物感镜头 skill，把参考图里的角色巨大化，写一个 10 秒的视频提示词。

生成的提示词可以直接用在 AI 视频生成模型里。
